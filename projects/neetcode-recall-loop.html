NeetCode Recall Loop.

A local Chrome extension that watches NeetCode problem attempts, prompting timed active recall checks and recommending pattern transfer neighbors.

View source ↗

Behind the build.

Grinding LeetCode and NeetCode often leads to passive recognition rather than long-term algorithmic intuition. Recall Loop is a client-side Chrome extension designed to enforce deliberate practice and defeat the forgetting curve directly in the browser.

  • Automated Recall Checkpoints: Prompts reflection after an accepted submission or after set time thresholds (15m Easy, 25m Medium, 40m Hard) without looking at solutions.
  • Pattern Neighbor Suggestions: Recommends 2–3 algorithmic sister problems based on problem tags to test conceptual transfer before moving on.
  • Dynamic Session Plan: Surfaces problems due for recall when landing on NeetCode, prioritizing spaced repetition over random problem selection.
  • 100% Client-Side Privacy: Practices and ratings are saved locally via Chrome’s storage.local API with zero external telemetry or authentication needed.

Built with: JavaScript, Chrome Extensions Manifest V3, Webpack, Local Storage API
