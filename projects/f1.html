A lap time tells you the result. Telemetry helps you explore how it happened. This project connects FastF1’s session data with Python analysis and Plotly visualizations to make racing data easier to investigate.

The visual above illustrates the idea: two traces can follow a similar shape while revealing differences in where speed builds and falls. Open the visualizer to explore the project.
