F1 Telemetry.

A Python tool for visualizing telemetry data from F1 races using FastF1 API.

Visit project ↗View source ↗

Behind the build.

This project visualizes F1 telemetry data using Python, integrating the FastF1 API to extract real-time race data, which is then displayed through Plotly visualizations. Features include:

  • Live race telemetry visualization
  • Telemetry data filtering and analysis
  • Real-time race monitoring

Built with: Python, Plotly, FastF1
