Behind the build.

The Civil Engineering Agent is an intelligent tool designed to assist with common civil engineering tasks and calculations. Currently, the agent can perform traverse calculations used in land surveying and mapping. Features include:

  • Open traverse calculations
  • Closed traverse calculations
  • Upcoming: Hydraulics calculations
  • Upcoming: Engineering markup tools
